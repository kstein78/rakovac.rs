## Zeitleiste

| Wann | Was geschah |
|---|---|
| vor etwa 7.000 Jahren | Bauern der Jungsteinzeit siedeln an der **Gradina**, im heutigen Novi Rakovac. |
| 3.–4. Jahrhundert n. Chr. | An derselben Stelle steht eine **spätrömische Villa** mit Fußbodenheizung (Hypokaustum). |
| 12. Jahrhundert | Eine Benediktinerabtei, in ungarischen Urkunden **Dombó** genannt, errichtet eine dreischiffige romanische Basilika von etwa 32 m Länge mit einer gemeißelten Chorschranke aus Marmor. Das genaue Baudatum ist umstritten. |
| 1237 | Der Abt von Dombó („Abbas de Dombo“) wird zum ersten Mal in einer Urkunde erwähnt. |
| 1416 | Abt Georg von Dombó wird von osmanischen Streifscharen gefangen genommen. |
| 1467–1473 | Die Abtei wird zu einer Festung mit Mauern, Toren und Graben umgebaut. |
| 1526 | Während des osmanischen Feldzugs, der bei Mohács endete, fällt die Festung Dombó. |
| Ende des 15. Jahrhunderts | Der Legende nach gründet **Raka**, Kämmerer des Despoten Jovan Branković, das Kloster Rakovac. |
| 1545–1546 | Das Kloster Rakovac erscheint in osmanischen Steuerregistern, sein erster verlässlicher Nachweis. |
| 1700–1714 | Die Schreibstube des Klosters kopiert das **Gesetzbuch des Zaren Dušan** (1700) und vollendet den **Srbljak von Rakovac** (1714). |
| 1735–1771 | Barocker Umbau: Glockenturm (1735), Ikonostase (1763), Malereien im Refektorium (1768), Wohntrakte (1771). |
| 1930er-Jahre | Der Steinabbau in **Beli Majdan** wird eingestellt. |
| 1941–1945 | Srem (Syrmien) wird besetzt. Steinbrucharbeiter und Dorfbewohner schließen sich den Partisanen an. 1943 wird das Kloster geplündert und gesprengt und das alte Dorf niedergebrannt. |
| nach 1945 | Das alte Dorf wird nicht wieder aufgebaut. Weiter unten im Tal wächst **Novi Rakovac**, und der alte Teil wird zu Stari Rakovac. |
| 1990 | Das Kloster wird zum Kulturdenkmal von außerordentlicher Bedeutung erklärt. Seine Kirche wird in den 1990er-Jahren restauriert. |
| 2022 | Die Volkszählung ergibt **2.137** Einwohner. |
